FIT-SLM-HC Decision Tool

Task-Technology Fit Framework for Small Language Models in Healthcare

Based on the FIT-SLM-HC framework — see citation below

This tool implements the three-step deployment-triage procedure from the FIT-SLM-HC framework. It helps healthcare organizations decide whether a candidate clinical task is suitable for a Small Language Model (SLM) deployed on local hardware, or whether a cloud-based Large Language Model (LLM) is required.

Score your task on three axes, enter your benchmark results, and the tool will compute an Accuracy Ratio (AR) and optional Latency Efficiency (LE), then compare your task against 25 benchmarked healthcare task configurations from the source manuscript (aug28 snapshot: 23 extended-table evaluation rows covering 22 unique tasks and one quantization variant, plus 2 vignette-only rows; one extended-table row, Pathology IE, is also Vignette A).

Step 1

Score Your Task

Characterize the candidate task on three axes. Score the dominant requirement of the intended workflow under normal operating conditions. When a task spans two levels, assign the higher (more conservative) level.

Reasoning Complexity (r) — number of logical steps from input to output
Knowledge Boundedness (k) — reliance on stored vs. provided knowledge
Output Structure (o) — constraints on the output format
Axis Sum: select all three axes

Score the task as it will be deployed, including any retrieval augmentation, templating, or workflow constraints that change the effective demands on the model.

Step 2

Enter System Metrics

Enter your SLM and reference model performance scores on the same metric to compute the Accuracy Ratio. Use the same evaluation set for both.
